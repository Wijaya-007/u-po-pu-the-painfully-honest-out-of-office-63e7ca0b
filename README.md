A tiny Node 22 (stdlib-only) program that writes one painfully honest out-of-office auto-reply to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> I am out of office until Monday, ignoring 214 unread emails and pretending the word 'urgent' is a rumour. For real emergencies, try someone else.
